# FinScan F350 DICOM Image-Quality QA / Acceptance Report Protocol

Version: `F350-QA-PROTOCOL-0.2`

## Purpose

This protocol defines the report generated by the Medical Line Georgia FinScan F350 QA workspace from a reconstructed CBCT DICOM series. The purpose of the report is to make the source DICOM data, ROI placement, quantitative calculations, criteria, external dosimetry inputs, algorithm version, and traceability visible to a competent authority or qualified medical physicist.

The report must not claim manufacturer certification or regulatory approval unless a separate written validation/approval reference is supplied.

## Source data and traceability

The report records:

- DICOM Manufacturer, Model, Device Serial Number and Software Version;
- Study/Acquisition Date, StudyInstanceUID and SeriesInstanceUID;
- Series Description / Protocol;
- image matrix, Pixel Spacing, Slice Thickness, kVp, tube current and exposure time where present;
- number of imported DICOM files;
- SHA-256 digest of the imported series;
- selected analysis slice;
- QA ROI coordinates and dimensions;
- software version and quantitative calculation-engine version.

## Image-quality measurements

### 1. Spatial resolution / MTF

The operator positions a rectangular ROI across the PVC/air edge of the phantom. The edge must be approximately parallel to the ROI rows. The software:

1. calculates the mean pixel value of every row;
2. calculates the first-order row differential;
3. finds the strongest edge and a symmetric data band around it;
4. zero-pads the data and applies a discrete Fourier transform;
5. creates a normalized MTF curve;
6. reports Nyquist frequency, MTF50 and MTF10.

Current review criterion: `MTF10 >= 1.0 lp/mm`.

### 2. CNRI

The operator positions a rectangular ROI across the PVC/PMMA edge. The software calculates row means and standard deviations, derives the transition rows using moving-average / differential processing, and calculates the DIN-style contrast-to-noise ratio index from the two detected material rows.

Current review criterion: `CNRI < 20`.

### 3. Uniformity Index H

Five circular homogeneous-material ROIs are placed at center, top, left, right and bottom. The software records mean and standard deviation for each ROI and calculates the uniformity index using the five-ROI method together with the measured PVC/PMMA contrast numerator.

Current review criterion: `H > 5`.

## Radiation-output section

DICOM data are not treated as an independent dosimeter measurement. A calibrated KAP meter reading can be entered together with:

- meter model and serial number;
- calibration certificate reference;
- calibration factor `Nk`;
- room temperature;
- atmospheric pressure;
- FOV width and height.

The software calculates corrected KAP using temperature/pressure correction and can normalize KAP to a 16 cm² reference FOV for comparison with the selected published dental-CBCT QA criterion.

Current review criterion for the normalized published-method metric: `<= 250 mGy·cm²`.

## Status logic

- `PASS`: all available mandatory image-quality and entered dose criteria pass.
- `ACTION`: at least one measured mandatory criterion is outside its action limit.
- `INCOMPLETE`: one or more mandatory measurements / external dosimetry inputs are missing.

The PDF separately reports `Image Quality Status`, `Dose Status`, and `Overall Status` so that a missing dose measurement cannot be hidden by a passing DICOM image-quality analysis.

## PDF report structure

1. Report identity, facility, operator, phantom and review status.
2. DICOM equipment and acquisition data.
3. Quantitative image-quality result table.
4. Selected DICOM slice with visible ROI overlays.
5. ROI coordinates and raw derived values.
6. MTF curve.
7. External KAP/dose measurement inputs and calculated values.
8. Calculation method/version and interpretation notes.
9. Regulatory-review statement and signature lines.

## Method basis

The implementation is based on published dental-CBCT QA methodology using a QUART DVT_AP-style phantom workflow, the EFOMP-ESTRO-IAEA CBCT QA framework, and DIN 6868-161 concepts. The exact local acceptance criteria and the acceptability of this software/report format must be confirmed by the competent Georgian authority / qualified medical physicist.
